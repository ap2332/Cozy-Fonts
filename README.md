# Cozy Fonts

Cozy Fonts 是 Minecraft Java 版資源包，取自零雾〇五（Fogg05）的 CozyUI Plus，僅保留字體。想沿用目前的介面外觀，同時使用 CozyUI Plus 的字體，可以單獨安裝這個版本。

[下載 Cozy Fonts.zip](https://raw.githubusercontent.com/ap2332/Cozy-Fonts/main/Cozy%20Fonts.zip)

## 安裝

1. 在 Minecraft 開啟「選項」→「資源包」→「開啟資源包資料夾」。
2. 將下載的 ZIP 原檔放入資料夾，無須解壓縮。
3. 回到遊戲，啟用 Cozy Fonts 並按「完成」。若其他資源包也會更換字體，請將 Cozy Fonts 移到它們上方。

## 原作

完整的 CozyUI Plus 由零雾〇五（Fogg05）製作，可在 [GitHub](https://github.com/Fogg05/CozyUI-Plus) 或 [Modrinth](https://modrinth.com/resourcepack/cozyui-plus) 查看。
